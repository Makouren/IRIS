LEGACY WORKFLOW FILE MAP AND CODE (IRIS V2.0.1)
================================

Historical reference only. The excerpts below predate the normalized `iris_db_3nf` conversion and may show retired table/column names. Do not use these snippets or the legacy `database.sql` to provision or modify the V4.5.0 database.

WORKSPACE ROOT
--------------
C:\xampp\htdocs\IRIS V2.0.1\IRIS

This is a Notepad-friendly map of the files for Office Upload, Review Editor,
Saved Graphs, Public Observatory, and shared chart rendering. Code blocks below
are the relevant wiring excerpts, not full copies of the source files. The path
labels identify where each full implementation resides.

WORKFLOW OVERVIEW
-----------------
Office user uploads a spreadsheet
    -> admin/office_upload.php
    -> admin/upload_process.php
    -> includes/SpreadsheetReader.php parses the spreadsheet
    -> records row is created with Pending Review status
    -> Super Admin opens admin/review_editor.php
    -> scanner/js/modules/studioWorkbench.js maps fields and saves a graph
    -> scanner/js/modules/chartEngine.js builds the preview options
    -> api/iris.php stores/loads saved graph data
    -> admin/saved_graphs.php renders saved graphs
    -> user/dashboard.php renders graphs whose is_published flag is true


1. OFFICE UPLOAD
================

FILE: admin/office_upload.php
ROLE: Office-facing upload form, upload history, and available templates.
NEXT FILE: The form submits to admin/upload_process.php.

Relevant form wiring:

    <form method="POST"
          action="<?= e(base_url('admin/upload_process.php')) ?>"
          enctype="multipart/form-data">
        <?= csrf_field() ?>
        <input id="officeFile" name="office_file" type="file"
               required accept=".xlsx,.csv,.tsv">
        <button type="submit">Send for review</button>
    </form>

Template list wiring:

    <div id="activeTemplatesList"
         data-api="<?= e(base_url('api/templates.php')) ?>"
         data-download-base="<?= e(base_url('admin/template_download.php')) ?>">

    <script src="<?= e(base_url('admin/js/officeTemplates.js')) ?>"
            defer></script>

FILE: admin/upload_process.php
ROLE: Validates the file, parses it, stores it outside the web root, and adds a
      Pending Review record associated with the uploading office/user.
USES: includes/functions.php and includes/SpreadsheetReader.php.

Relevant parse and record insert:

    $parsed = (new SpreadsheetReader())->parse(
        $file['tmp_name'], $extension, (string)$file['name']
    );

    $insert = $pdo->prepare("INSERT INTO records
        (id, fileName, fileType, fileSize, scannedAt, status, uploaded_by,
         office_name, uploaded_at, docType, rawText, extractedData,
         graphDrafts, adminNotes, metadata, updatedAt)
        VALUES (?, ?, ?, ?, NOW(), 'Pending Review', ?, ?, NOW(), ?, ?, ?, ?, '', ?, NULL)");

The handler finishes by returning the uploader to office_upload.php with a
success or error flash message. It does not publish a chart by itself.

FILE: admin/js/officeTemplates.js
ROLE: Client-side behavior for the Active Templates section on office_upload.php.

FILE: includes/SpreadsheetReader.php
ROLE: Reads XLSX, CSV, and TSV data for the office upload handler.

FILE: includes/functions.php
ROLE: Shared PHP helpers used by upload, authentication, URL generation, and DB
      access. The office upload page and upload handler both require it.

ROLE: Read endpoint for public graphs. Selects only saved graphs marked
      is_published = 1, and returns chart_data, config metadata, labels, values,
      source details, and field colors.

Relevant query fields:

    SELECT sg.id, sg.record_id, sg.title, sg.chart_type, sg.orientation,
           sg.colors, sg.chart_data, sg.value_axis_reversed,
           sg.value_axis_min, sg.value_axis_max, sg.rank_semantic,
           sg.rank_value_min, sg.rank_value_max, sg.labels, sg.values_data,
           sg.is_published, sg.created_at
    FROM saved_graphs sg
    WHERE sg.is_published = 1


5. SHARED CHART CODE
====================

FILE: scanner/js/modules/chartEngine.js
ROLE: One ECharts option builder for Studio, Saved Graphs, and the public view.
      Also owns the Studio row-to-chart transformation and saved-graph adapter.

Relevant exports and call sites:

    export function buildChartOption({
        type, labels, values, rawValues, series, config, colors,
        theme, precision, context, showTitle
    } = {}) { ... }

    export function buildSavedGraphOption(graphData, options = {}) {
        // Normalize saved graph payload, resolve colors, then call builder.
        return buildChartOption({ ... });
    }

    export function createChart(element, type, graphData, options = {}) {
        const chart = window.echarts.init(element);
        chart.setOption(buildSavedGraphOption(graphData, options));
        return chart;
    }

FILE: scanner/js/chartData.js
ROLE: Groups/aggregates rows and serializes real graph values and series before
      Studio saves a graph.

FILE: scanner/js/chartMapping.js
ROLE: Infers category/value fields and parses numeric, rank, and year values.

FILE: scanner/js/chartColors.js
ROLE: Resolves field-specific and custom colors used by Studio and saved views.

FILE: scanner/js/graphExport.js
ROLE: Normalizes graph exports and constructs printable graph sheets.

FILE: scanner/js/ai/graphEngine.js
ROLE: Generates chart drafts from spreadsheet data. Draft cards are rendered by
      scanner/js/modules/graphsTab.js, which mounts them through chartEngine.js.

FILE: scanner/js/modules/graphsTab.js
ROLE: Draft chart cards in the Scanner workspace; uses createChart() for rendering.

FILE: scanner/js/modules/README.md
ROLE: Developer notes about module responsibilities and chart rendering.
